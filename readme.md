# How To RUN!
## init ->
create dir: `sudo mkdir -p /front/`

clone from git repo: `git clone https://git.atishahr.net/mehdimj/sibpanel_v2_dockerized.git proj_name` 

cd to *proj_name* && init project: `git submodule update --init`

after then for update just type `git submodule update --remote`

##### P.S:
*proj_name* is `iranfun` or `municipality` or `tourism`
